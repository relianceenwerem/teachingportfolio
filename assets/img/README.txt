Images for the teaching portfolio
=================================

All artwork on the site is built-in SVG, so the site looks complete with no image
files at all. These optional JPGs let you swap in real photos where you'd like them.
Each one falls back to on-theme artwork automatically if the file is not present.

Optional files (drop them in this folder with these exact names):

  portrait.jpg    About page portrait.  Portrait orientation, ~4:5 (e.g. 600 x 750).
  teaching-1.jpg  About gallery, "Data by hand".       Landscape, ~4:3 (e.g. 800 x 600).
  teaching-2.jpg  About gallery, "Redesign for care".  Landscape, ~4:3.
  teaching-3.jpg  About gallery, "Peer dialogue".      Landscape, ~4:3.

Larger images are fine; they are scaled and cropped to fill their frames.
